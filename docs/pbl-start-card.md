# PBL 시작 카드

## 프로젝트

- 프로젝트 주제: 쇼핑몰 상품 검색
- 사용자: 상품명·가격·재고·평점을 비교해 구매할 상품을 찾는 쇼핑몰 고객
- 해결하려는 문제: 상품이 많을 때 원하는 상품을 이름으로 찾고 조건을 적용해 비교하기 어렵다.
- ES로 찾게 할 문서 한 건: 검색 결과 목록에 표시되는 상품 한 건
- index 이름: `my-products`
- 업무 ID field: `prd_id`
- 업무 ID와 ES `_id` 사용 계획: 같은 값을 사용하되 두 값이 자동으로 동기화되지는 않음을 확인한다.

## 사용자 질문

1. 무선 이어폰 상품을 찾아줘.
2. 재고가 있는 전자기기 중 가격이 5만 원 이상 20만 원 이하인 상품을 낮은 가격순으로 보여줘.
3. 평점이 4.5 이상인 상품을 평점이 높은 순서로 보여줘.

## 검색에 사용할 field

- 전문 검색: `prd_nm`
- 정확 조건: `category`, `in_stock`
- 범위 조건: `price`, `qty_score`
- 정렬: `price`, `qty_score`
- 결과 표시: `prd_id`, `prd_nm`, `category`, `price`, `in_stock`, `qty_score`

## 성공 기준

- 상품명에서 “무선 이어폰”을 검색할 수 있다.
- `category`, `in_stock`, `price` 조건을 함께 적용하고 낮은 가격순으로 정렬할 수 있다.
- `qty_score` 4.5 이상을 조건으로 적용하고 높은 평점순으로 정렬할 수 있다.
- 최소 1,000건의 합성 상품 데이터를 적재하고 count와 주요 분포를 실제 응답으로 검증한다.
- 카테고리별 상품 수와 평균 가격을 Dashboard에서 확인한다.

## 범위

- 웹사이트 전체가 아니라 ES index, 검색 요청, 분석과 Dashboard를 완성한다.
- 실제 고객 개인정보와 주문 정보는 사용하지 않는다.
- 합성 상품 데이터만 사용한다.
