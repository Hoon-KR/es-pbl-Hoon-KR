## V1-T11-P · field 계약

| field | 예시 값 | 검색/필터/정렬/표시/집계 | type | 질문 번호 | 선택 이유 |
|---|---|---|---|---|---|
| `product_id` | "AD-1004" | 표시 | keyword | 공통 | 문서 고유 식별 및 상세 페이지 연동 |
| `product_name` | "소니 WF-1000XM4" | 검색, 표시 | text | 공통 | 제품명 검색을 위한 형태소 분석 필요 |
| `brand` | "Sony" | 필터, 표시, 집계 | keyword | Q3 | 특정 브랜드 지정 검색 및 통계용 |
| `category` | "이어폰" | 필터, 집계 | keyword | Q1, Q2, Q3 | 폼팩터(형태) 기준 명확한 분류 필요 |
| `connection` | "무선" | 필터, 집계 | keyword | Q1, Q2 | 유무선 여부에 따른 정확한 필터링 |
| `price` | 95000 | 필터, 정렬, 표시 | integer | Q1 | 가격 상한선/하한선 검색 및 저가순 정렬 |
| `features` | ["노이즈 캔슬링", "방수"] | 검색, 필터, 표시 | keyword | Q1 | 제공 기능 포함 여부를 정확히 일치시켜야 함 |
| `battery_hours` | 35 | 필터, 정렬, 표시 | integer | Q2 | 최소 사용 시간 기준 필터 및 정렬 |
| `rating` | 4.6 | 필터, 정렬, 표시 | float | Q3 | 소수점 평점 비교(>= 4.5) 및 평점순 정렬 |
| `review_summary`| "저음이 좋고 운동용으로 딱입니다" | 검색, 표시 | text | Q2 | 리뷰 내용 속 추상적 키워드(저음, 운동용) 검색 |

- 배열/객체 여부와 제공 생성기 지원 범위: `features` 필드는 단일 문자열이 아닌 여러 기능을 담는 배열(Array of Strings)로 구성합니다. 복잡한 Nested 객체 대신 단일 뎁스(Flat) 구조를 사용하여 데이터 생성기(파이썬 스크립트 등)에서 리스트 형태로 쉽게 생성할 수 있도록 설계했습니다.
- 제외한 개인정보/불필요한 field와 이유: 리뷰 작성자의 '실명, 이메일, IP 주소'는 개인정보 보호 및 시스템 분석 목적(제품 특성 파악)과 무관하므로 설계에서 제외했습니다.
- 자가 점검으로 수정한 내용: 카테고리(`category`)와 브랜드(`brand`) 필드를 처음에는 `text`로 생각했으나, 정확한 일치(Exact Match) 필터링과 Dashboard 집계(Aggregation)를 위해 `keyword` 타입으로 수정했습니다. 반면, 리뷰와 제품명은 단어 단위 검색이 필요해 `text` 타입으로 명확히 구분했습니다.
