# PBL 시작 카드

- 프로젝트 주제: 음향기기(이어폰, 헤드셋 등) 스펙 및 사용자 리뷰 통합 검색 및 분석 시스템 구축
- 사용자는 누구인가: 예산, 선호하는 음색, 사용 목적(운동, 게이밍, 작업 등)에 맞춰 최적의 음향기기를 찾으려는 일반 소비자 및 오디오 애호가
- ES로 찾게 할 문서 1건은 무엇인가: 특정 음향기기 모델 1개의 '상세 스펙 및 가상의 종합 리뷰 데이터' 1건 (제품명, 브랜드, 가격, 스펙, 리뷰 텍스트 등이 포함된 JSON 문서)
- 사용자가 입력할 검색 질문 1: "노이즈 캔슬링이 지원되는 10만 원 이하 가성비 무선 이어폰" (기능 + 가격 + 형태 검색)
- 사용자가 입력할 검색 질문 2: "저음이 강조되고 배터리가 오래가는 운동용 블루투스 헤드셋" (음색 + 스펙 + 용도 검색)

- 사용자가 입력할 검색 질문 3: "소니나 보스 제품 중 사용자 평점 4.5 이상인 오버이어 헤드폰" (브랜드 + 평점 + 형태 검색)
- 필터에 사용할 분류 필드 후보: 브랜드 (brand: Sony, Bose, Apple 등)

카테고리 (category: 인이어 이어폰, 오픈형 이어폰, 오버이어 헤드폰 등)

연결 방식 (connection_type: 유선, 무선, 완전무선)

주요 기능 (features: 노이즈 캔슬링, 방수, 공간음향 등 배열 데이터)
- 정렬에 사용할 숫자·날짜 필드 후보: 가격 (price)

평균 평점 (average_rating)

리뷰 개수 (review_count)

최대 재생 시간 (battery_life_hours)

출시일 (release_date)

- Dashboard에서 답할 질문 1: "브랜드별 및 폼팩터(이어폰/헤드셋)별 평균 평점과 리뷰 수는 어떻게 분포되어 있으며, 특정 가격대(예: 10~20만 원)에서 가장 인기 있는 주요 기능(노이즈 캔슬링 등)의 비율은 어떠한가?"

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아닙니다. ES index, 검색 요청, 분석·Dashboard를 완성합니다.
- 실제 개인정보·고객 데이터는 사용하지 않습니다.
- 최소 1,000건, 권장 5,000~10,000건의 합성 데이터를 사용합니다.
